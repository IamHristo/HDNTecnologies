# HDN Technologies website

Source for [hdntechnologies.com](https://hdntechnologies.com), the website of
Ейч Ди Ен Технолоджийс ЕООД (HDN Technologies EOOD), Plovdiv, Bulgaria.

The site is plain static HTML and CSS generated by [Eleventy](https://www.11ty.dev/) at build time.
Visitors receive **zero JavaScript** and **zero third-party requests** (no CDNs, web fonts, analytics or trackers).

## Quick start

```sh
npm ci          # install the pinned build tool (install scripts are disabled via .npmrc)
npm run serve   # local dev server on http://localhost:8080 with live reload
npm run check   # production build into _site/ + output verification
```

Requires Node.js 20 or newer.

## Project structure

```
src/
  _data/
    site.json          company facts – single source of truth (legal name, ЕИК, VAT, email, links)
    locales.json       enabled languages (code, hreflang, og:locale, endonym, URL prefix)
    pages.json         page keys -> paths, shared by every language
    i18n/<code>.json   all visible text per language (en.json is the reference)
  _includes/
    layouts/base.njk   <head>, CSP, canonical/hreflang, OpenGraph, JSON-LD, header, footer
    partials/          header, footer, language switcher
    diagrams/          inline SVG illustrations and the anonymised architecture figure
  pages/               home, privacy, 404 – each generated once per enabled language
  assets/              CSS and images, copied as-is
  sitemap.xml.njk      generated from pages.json x locales.json
  llms.txt.njk         AI-readable site summary, generated from the same strings
  robots.txt, CNAME    copied as-is
design/brand-assets.html source for og.png, logo-512.png and apple-touch-icon.png (not published)
scripts/verify-dist.mjs  zero-dependency checks on the built output
eleventy.config.js       translation loader/validator, URL filters, JSON-LD generator
```

Structured data (Organization/ProfessionalService, WebSite, WebPage, Service, FAQPage, BreadcrumbList) is built
in `eleventy.config.js` from the same translation strings as the visible page, so it cannot drift from the content.

The automotive case study is under NDA: never add client names, brands, screenshots, metrics or the real topology.

`_site/` is the build output and the **only** directory deployed to GitHub Pages.

## Adding a language

1. Copy `src/_data/i18n/en.json` to `src/_data/i18n/<code>.json` and translate every value.
2. Add the locale to `src/_data/locales.json`, e.g.
   `{ "code": "de", "hreflang": "de", "ogLocale": "de_DE", "endonym": "Deutsch", "prefix": "/de", "isDefault": false }`.
3. Run `npm run check`.

The build **fails** if a translation file is missing keys or has extra ones, so a page can never fall back to
English silently. hreflang tags, sitemap alternates, the 404 page and the language switcher update automatically
(inline links up to 3 languages, a no-JS `<details>` menu above that).

## Deployment

`.github/workflows/static.yml` runs on every push and pull request to `main`:
`npm ci --ignore-scripts` → `npm run build` → `npm run verify` → upload `_site/` → deploy (on `main` only).
Actions are pinned to commit SHAs.

`npm run verify` fails the build if the output contains internal files (README, `.vscode`, sources),
executable scripts, inline handlers or styles, third-party resources, unsafe external links, invalid JSON-LD,
or sitemap URLs without a page.

## Security model (GitHub Pages free tier)

GitHub Pages cannot send custom HTTP headers, so the baseline is:

- every page carries a strict meta CSP: `default-src 'none'; style-src 'self'; img-src 'self'; base-uri 'none'; form-action 'none'; upgrade-insecure-requests`
  (`frame-ancestors`, `report-uri` and `sandbox` are ignored in `<meta>` by browsers – accepted, the site has no
  logins or state-changing actions);
- `<meta name="referrer" content="strict-origin-when-cross-origin">`;
- no JavaScript, no third-party resources, external links use `rel="external noopener noreferrer"`;
- GitHub repository settings: **Enforce HTTPS** on, and the custom domain **verified** (Settings -> Pages) to prevent takeover.
